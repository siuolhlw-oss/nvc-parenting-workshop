# 約定之後，聽見彼此

100 分鐘親職善意溝通網頁簡報。以詠春拳父女案例，練習辨識 4D、理解雙方需要、重新訂定約定，以及事後道歉與修補。

## 使用

- 左右方向鍵換頁，空白鍵揭示參考答案。
- 答案可收起，章節可直接跳轉，每頁有帶領筆記。
- 26 個主問題、5 個備用情境。情境頁與整理頁另列。
- 影片嵌入 YouTube，另保留原片連結。離開影片頁會停止播放。
- 支援電腦與手機。線上會議的系統聲音分享需在會議軟體設定。

## 時間

0–8 暖身、8–20 影片與 4D、20–32 觀察、32–52 需要、52–70 約定、70–85 道歉、85–97 演練、97–100 收束。備用題用來替換部分討論。

## 編輯與發布

純 HTML、CSS、JavaScript，不需安裝套件或建置。`content.js` 放內容，`app.js` 控制換頁與揭示，`style.css` 延續參考簡報樣式，`workshop.css` 調整這份演練的版面。

使用 GitHub Pages，從 `main` 分支根目錄發布。`.nojekyll` 停用 Jekyll 處理。
